# SoundLabs.Blazor

Клиентское приложение Blazor WebAssembly для АИС «SoundLabs».

## Дизайн
- Тёмная музыкальная тема, преобладающий цвет — бордовый: `#19171b`, `#75020f`, `#51080d`, `#2b0307` + кремовый `#f3ebe0` (все цвета — переменные в начале `wwwroot/css/app.css`).
- Шрифты Unbounded, Cormorant Garamond и Manrope (Google Fonts, есть кириллица).
- Плавность: переход между страницами, появление блоков при прокрутке (`wwwroot/js/site.js`), плавные наведения, меню на мобильных, `scroll-behavior: smooth`. При включённой в системе настройке «уменьшить движение» анимации отключаются.
- Вместо фотографий везде стоит заглушка с гитарой: `wwwroot/images/placeholder.jpg` (оригинал, для карточек товаров) и `placeholder.png` (без фона, для крупных блоков). Когда появятся реальные фото, замените пути `images/placeholder.*` в `Pages/*.razor`.

## Требования
- .NET 10 SDK
- Запущенный `SoundLabs.Api`
- PostgreSQL с подготовленной БД `soundlabs`

## Запуск
1. Запустите API SoundLabs.
2. Откройте `wwwroot/appsettings.json` и укажите фактический адрес API в `ApiBaseUrl` (например, `https://localhost:7001/`). Адрес должен оканчиваться `/`.
3. В каталоге проекта выполните:

```bash
dotnet restore
dotnet run
```

4. Откройте URL, который выведет `dotnet run`.

## Реализовано
- Главная страница, категории и каталог с поиском; поиск из шапки и ссылки на категории (`/catalog?search=…`, `/catalog?categoryId=…`) работают без перезагрузки страницы, поэтому корзина не очищается.
- Получение товаров и категорий через `GET api/products`, `GET api/categories`.
- Регистрация и вход через `api/auth/register` и `api/auth/login`; JWT хранится в localStorage.
- Корзина и оформление заказа через `POST api/orders`.
- Просмотр заказов и изменение статуса менеджером через `api/orders`.
- Каталог услуг и создание заявки на ремонт через `api/services`, `POST api/repairs`.
- Просмотр заявок и изменение статуса мастером через `api/repairs`.
- Управление товарами для менеджера/администратора через `POST/PUT/DELETE api/products`.

## Важно
Фронтенд использует только API-методы, обнаруженные в приложенном `SoundLabs.Api.zip`. В API пока отсутствуют методы для управления сотрудниками, поставщиками, поставками, складскими запчастями и системными журналами, поэтому эти разделы не имитируются на стороне интерфейса. Измените `ApiBaseUrl` на адрес своего API. При локальном HTTPS может потребоваться доверить сертификат разработчика (`dotnet dev-certs https --trust`).

Тестовые учётные записи из README API: `admin`, `manager1`, `master1`, `client1`; пароль `Pass123!` (если база заполнена тестовыми пользователями).
